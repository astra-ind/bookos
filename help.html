Common questions

How do I install BookOS?
Download the Windows installer from the Download page and run it — the wizard covers install location and shortcuts. Your books are not stored in the install directory; they live in .bookos project folders you choose, so reinstalling or uninstalling never touches your writing. Full steps: Installation →
How do I create a project?
Launch BookOS and choose New Project on the home screen. Pick a kind — Book, Series, Universe, or Nonfiction — give it a name, and you're in. A project can hold one book or an entire universe. Details: Creating your first project →
How do I import a manuscript?
Inside a book, run Import (File menu) and choose a DOCX, TXT, Markdown, HTML, or EPUB file. Chapters are extracted and you're offered an analysis pass that proposes characters, locations, mysteries and a chapter map — each proposal reviewed before anything enters the Book Brain. Nothing is committed automatically.
How does the Book Brain work?
The Book Brain is a persistent model of your story held in the project's local database: canon records, live character states, who knows what, timeline, mysteries, setups and payoffs, research and your notes. It updates in two ways: automatically through ambient extraction that proposes what new prose established (you ratify), and manually through the boards. Every AI operation reads a surgical packet from it. See What the Book Brain knows →
How do AI agents work?
Agents are specialists with declared permissions — the Critic cannot write prose, the Writer cannot touch canon. You invoke them through selection actions, workflows, or Autopilot; their output arrives as reviewable changes on the manuscript or as proposals, never as silent edits. Every run is logged and inspectable. See AI agents →
Can I use my own API key?
Yes — that's the design. Settings → AI Providers accepts OpenAI, Anthropic, Google, any OpenAI-compatible endpoint, and local models. Keys are stored in your operating system's credential vault, never in project files or backups. See AI providers & API keys →
Does BookOS work offline?
Completely. Writing, planning, continuity audits, search, exports, and backups are all local. A built-in offline embedder powers semantic search with no provider at all. Only AI generation calls out to the network — through providers you configured — and the app degrades loudly and honestly if that's unavailable.
How do I restore an older version?
Three ways. Chapter version history offers side-by-side diff and restore. BookGit snapshots are taken automatically before merges and risky operations — find them in Version Control. And one-click backups are restorable gzip archives of the whole project. Your own copy of the .bookos folder is always a backup too.
How do I export my book?
Export supports DOCX (professional presets, real Word TOC field, headers/footers, auto-bibliography from citations), PDF, EPUB, Markdown, HTML, and TXT. Everything is composed from the canonical manuscript at export time — nothing destructive, nothing baked into your text. See Export & backup →
How do I report a bug?
Email support@bookos.app with what you did, what you expected, and what happened. If it involves a crash or data concern, include the version from Settings → About. Project files themselves contain your writing — only attach them if you're comfortable doing so.
